Run Ralph via `docker compose`, mounting the Ralph repo at `/app` (read-only) and the caller's destination repo at `/app/dest_repo` (read/write). Compose sets `DEST_REPO=/app/dest_repo` so `.ralph` metadata is read/written under the mounted destination. Export `RALPH_REPO_HOST_PATH` and `DEST_REPO_HOST_PATH` with absolute host paths for volume mounts (used by `docker-compose.yml`).
